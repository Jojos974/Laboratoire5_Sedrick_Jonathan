# 243-557 — DiagnosticTool

Projet fil conducteur du cours **243-557 — Programmation et systèmes**.

Cette application évoluera progressivement pendant les laboratoires afin de devenir un logiciel de diagnostic capable de communiquer avec un système embarqué.

## Fonctionnement initial

La version initiale contient une interface graphique PyQt6 permettant de simuler la lecture d’un capteur.

## Prérequis

- Python 3
- PyQt6

## Installation des dépendances

À partir de la racine du projet :

```powershell
python -m pip install -r requirements.txt
```

## Exécution

À partir de la racine du projet :

```powershell
python src\main.py
```

## Structure initiale

```text
src/
├── main.py
└── main_window.py
```
L’architecture et les fonctionnalités du projet seront enrichies progressivement pendant la session.
